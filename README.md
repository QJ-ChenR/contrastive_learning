# contrastive_learning

基于产物结构关系的 BGC 监督式对比学习项目。

创建日期：2026-11-20（Europe/Paris）。

**当前状态：项目说明与实验设计阶段。** 当前仅创建本目录和 README；尚未在本项目中下载数据、构建训练集、实现训练代码或启动训练。下文区分已经讨论的研究方向、首轮候选方案和待验证事项，不代表所有实验细节已经确定。

## 1. 项目目标

学习能够独立表示单个生物合成基因簇（BGC）的向量，使产生相似天然产物的 BGC 在向量空间中更接近，用于 BGC 相似性检索，并通过聚类检验其家族组织能力。

核心研究问题：在预训练蛋白质模型的表示之后，训练 BGC 聚合器，能否比冻结 ESM2 的简单聚合获得更符合产物关系的表示？这种改善能否迁移到独立的 curated GCF 聚类任务？

需要始终区分三个目标：

- **产物结构关系**：本项目首轮候选监督的依据。
- **生物合成机制与模块组成**：解释、核验和可能的辅助监督依据。
- **GCF 归属**：独立的家族评估目标，不与产物结构相似性自动等同。

共享 NRPS、PKS 等粗类别不能直接证明两个 BGC 应组成正例；相似产物也不一定来自相同机制或同一家族。

### 3.2 产物相似度定义

作者代码使用 `GetRDKitFPGenerator(fpSize=8192)` 生成 RDKit 指纹，再计算 Tanimoto 相似度。对两个多产物 BGC，取所有产物配对中的最大值：

\[
S_{ij}=\max_{a\in P_i,\,b\in P_j}
\operatorname{Tanimoto}(\operatorname{FP}(a),\operatorname{FP}(b))
\]

其中 `P_i` 为 BGC `i` 已记录的产物集合。高分表示至少一对已知产物相似，不代表整个产物集合相同；低分也可能受到产物记录不完整的影响。

监督分值来自已知产物结构的化学计算，不来自 BiG-SCAPE 的预测家族。该分值也不是实验测得的功能相似度。

## 4. 首轮候选方案：阈值配对监督

用户提出：对每两个不同 BGC，按产物相似度阈值构建正负对。首轮候选阈值为 **0.65**：

\[
y_{ij}=\begin{cases}
1, & S_{ij}>0.65 \\
0, & S_{ij}\leq0.65
\end{cases}
\qquad i\ne j
\]

该规则仅应用于具有有效产物信息和有限相似度值的配对。缺失、无法计算或身份不明的关系保留为未知，不自动标负。

这是增加**配对监督**，没有增加独立生物样本。1438 个 BGC 在任何筛选和划分之前，最多有 `1438 × 1437 / 2 = 1,033,203` 个无序非自身配对。A–B 与 B–A 不是两个独立样本；大量配对也不会消除物种、家族和化学空间的覆盖偏差。

**0.65 尚未经过验证。** 应固定指纹定义，并在训练／验证范围内研究阈值与正例覆盖、标签稳定性和检索表现之间的关系，不使用测试成绩挑选阈值。

配对关系不要求传递：A–B 和 B–C 为正，不代表 A–C 必须为正。因此保留逐对关系，不把正例图的连通分量直接转换成互斥家族标签。

### 可选对照，尚未定为必须实施

- **双阈值灰区**：`S > tau_pos` 为正，`S < tau_neg` 为负，`tau_neg < tau_pos`；中间关系不施加约束。使用对比损失时，灰区也必须从负例集合中排除。
- **相似度加权多正例**：依据连续相似度调整正例权重，检验是否优于硬阈值。
- **排序或连续相似度辅助目标**：用于后续比较，不要求向量余弦值精确等于化学相似度。

初始实验优先保留简单阈值方案。具体损失、边界约定以外的超参数、灰区范围和采样比例仍待确定。

## 5. 模型与输入计划

当前建议的起点是：

```text
BGC → 现有蛋白／域输入解析 → 冻结 ESM2 token 表示
    → 可训练 BGC 聚合器／投影 → 归一化 BGC 向量
```

两个 BGC 通过共享编码器分别产生独立向量，以余弦或距离参与对比学习。产物结构只用于构造训练监督；推理和检索时只需要 BGC 输入。

- 首轮考虑训练聚合器，保留冻结 ESM2 简单聚合为对照。attention 的具体层数、池化方式、输出维度尚未决定。
- 现有蛋白流程以 `aSDomain` 切分；没有相应注释的 CDS 使用完整翻译。Pfam 坐标切分仍是此前暂缓的方向，不在本项目创建时改变。
- 保持已有长蛋白处理策略并记录其配置。复用缓存前检查输入序列、分段、池化、模型和源码的对应关系，不能只凭 BGC ID 对齐。
- 学习目标在 BGC 层面计算，不把 BGC 的产物关系直接复制为每条蛋白的功能标签。
- ESM2 LoRA／部分解冻可作为后续比较，当前未确定实施；固定 token 缓存不能支持 ESM2 反向传播。
- DNA 融合属于后续可选方向。DNA encoder 已支持任意长度输入，不重新引入历史 DNA 长度过滤；资源失败需单独记录。

## 6. 数据审计与划分原则

未来准备数据时，原始下载内容存入 `data/raw/`，派生清单、修订输入和划分存入 `data/processed/`，不覆盖原始文件。当前这些子目录尚未创建。

先完成以下审查，再确定训练队列：

1. 固定作者数据版本／提交、下载来源和文件哈希；核对源表、矩阵、产物列表、GBK 的身份对应及覆盖。
2. 检查矩阵行列 ID、对称性、对角线、数值范围、缺失值和重复项；复核修订版产物关系。
3. 检查 DNA 正反互补重复、边界包含、蛋白重复及近同源；保留重复和冲突证据。
4. 隔离与所有预留评估集合的重合，再按 BGC／同源组划分训练、验证和测试。
5. **划分完成后，分别在各集合内部生成配对。禁止随机拆分配对行来代替 BGC 划分。** 同一 BGC 的所有产物、蛋白、域和派生视图随其所属组移动。
6. 如果评估未见化学骨架的迁移，需要另外定义化学分组，并考虑每个 BGC 的全部已知产物；该协议尚未确定。

现有 MIBiG 审计发现，本地参考中有 **301 个唯一条目**与 B/E/G/H 存在确证的编号或 DNA 整体／完整包含重合，另有 `BGC0002037` 待复核。这些是对应旧审计输入的证据，不是本项目 1438 条候选的现成排除数量。仍需针对新输入重新对应，近同源隔离也尚未完成。

A/C/D/F/I 五个 curated 集合可作为后续监督候选，但尚未决定纳入本项目训练。它们存在来源集中、标签冲突、跨集重复和家族粒度差异，不能直接拼接成统一训练真值。

## 7. 训练前需要量化的监督规模

首先统计各候选阈值下：

- 正对、负对、未知关系的数量和比例。
- 每个 BGC 的正邻居数量，以及没有正例的 BGC 比例。
- 正例是否集中于少数家族、近重复序列或具有多个已知产物的 BGC。
- 阈值附近配对的数量，按生物合成类别、来源和序列相似度分层的分布。
- 去重、评估隔离和划分后，实际可用的 BGC、正例关系及生物覆盖。

目前没有计算 0.65 阈值下的上述统计。不能用候选配对总量代替有效监督规模。

采样优先考虑以 BGC 为锚点，再选择正负例，控制大族和容易负例对训练的支配。没有正例的 BGC 如何参与损失或负例池需显式定义，不因其无法作为正例锚点就静默删除评估样本。

## 8. 评估计划

同时评估产物检索和家族组织能力：

| 评估目标 | 候选指标／方式 |
| --- | --- |
| 产物结构相似性检索 | 在未见 BGC 上，以产物相似度作为相关性，评估 nDCG@K 等；K、增益函数和查询资格待确定 |
| 相似度排序 | BGC 向量相似度与产物相似度的 Spearman 相关性；报告配对覆盖和分层结果 |
| GCF 聚类 | 延续原始 cosine＋average-linkage／HDBSCAN，报告 V-measure、ARI、簇数、覆盖和噪声比例 |
| 泛化与偏差 | 分别检查同源隔离、未见家族／来源、类别及注释完整性等情形 |

B/E/G/H 已经参与前期方法比较与设计决策，可以保留为固定比较集合，但不能称为从未接触的盲测集。希望获得严格外部泛化结论时，需要另外预留独立数据。

保留冻结 ESM2、已有 BGC-MAC 和适用的 BiG-SCAPE 结果作为参照，核实同一输入与有效样本范围。既有 average-linkage 按真实家族数选择切割属于标签辅助诊断；用于部署的参数应在开发数据上确定。HDBSCAN 噪声样本不能从评分中静默去掉。

评价模型时，不能只看训练损失、配对准确率或 UMAP 图形。产物关系监督的提升也不保证 GCF V-measure 同步提高。

## 9. 下一步工作顺序与当前边界

1. 审阅并固定修订 MIBiG–NPAtlas 数据快照，建立可追溯的样本与产物清单。
2. 完成与预留评估集的重合／同源审查，提出可复现的划分。
3. 统计 0.65 候选阈值的正负对与锚点覆盖，比较少量预先定义的阈值。
4. 确定输入策略、聚合器、损失、采样和评估协议后，编写服务器训练流程。
5. 比较简单阈值基线、必要对照和独立检索／聚类结果，再决定是否扩展模型或数据。
